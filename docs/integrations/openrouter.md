# OpenRouter

## What it unlocks

OpenRouter lets the app call supported language models through one API account.

## Cost

Model prices and account terms vary. Check [OpenRouter's model catalog and pricing](https://openrouter.ai/models) before choosing a model.

## Get your key

1. Create or sign in to an account at [OpenRouter](https://openrouter.ai/).
2. Create an API key in your account settings and keep it private.

## Connect it

In the setup wizard or Settings, choose **OpenRouter**, enter the exact model ID shown in the OpenRouter catalog, paste your key, and select **Test**. Save the settings.
