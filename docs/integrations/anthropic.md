# Anthropic

## What it unlocks

Use Anthropic's Claude models to draft and review CVs, cover letters, and outreach.

## Cost

Anthropic charges for API use according to the selected model and token usage. See [Anthropic pricing](https://www.anthropic.com/pricing) for current rates.

## Get your key

1. Create or sign in to an account at [Anthropic Console](https://console.anthropic.com/).
2. Open API keys and create a key. Copy it somewhere private; it is a secret.

## Connect it

In the setup wizard or Settings, choose **Anthropic**, select a model, paste the key, and select **Test**. Save the settings. Never share the key or add it to a support request.
