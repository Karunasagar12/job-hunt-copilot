# Firecrawl

## What it unlocks

Firecrawl can search public web pages to support optional salary estimates. Salary research may be incomplete; compare the estimate with other sources.

## Cost

Firecrawl plans and usage credits can change. Check [Firecrawl pricing](https://www.firecrawl.dev/pricing) before use.

## Get your key

1. Create or sign in to an account at [Firecrawl](https://www.firecrawl.dev/).
2. Create an API key in the dashboard and store it privately.

## Connect it

In Settings, find the Firecrawl card, paste the API key, select **Save**, and then **Test**. Salary search remains optional and does not block applications.
