# AgentMail

## What it unlocks

AgentMail provides an inbox for application outreach and follow-up tracking. Job Hunt Copilot creates drafts; you review and send them yourself.

## Cost

Check [AgentMail's current plans](https://agentmail.to/pricing). Plans and usage limits may change.

## Get your key

1. Create an account at [AgentMail](https://agentmail.to/).
2. Create an inbox and copy its inbox ID.
3. Create an API key and store it privately.

## Connect it

In Settings, find the AgentMail card, paste the API key and inbox ID, select **Save**, and then **Test**. Review drafts in the connected inbox before sending.
