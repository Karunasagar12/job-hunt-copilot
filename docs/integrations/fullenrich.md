# FullEnrich

## What it unlocks

FullEnrich can look up business contact information for people you choose to approach. Treat a match as a suggestion and review it before outreach.

## Cost

Plans and lookup credits can change. Check [FullEnrich](https://fullenrich.com/) for current plan and usage details.

## Get your key

1. Create or sign in to an account at [FullEnrich](https://fullenrich.com/).
2. Create an API key in the account dashboard and keep it private.

## Connect it

In Settings, find the FullEnrich card, paste the API key, select **Save**, and then **Test**. Contact discovery is optional; the rest of the job workflow works without it.
